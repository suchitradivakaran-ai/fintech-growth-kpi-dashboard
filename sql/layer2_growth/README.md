## Layer 2: Core Metrics – User Growth

This layer focuses on establishing baseline growth metrics for the platform.
SQL queries in this folder compute daily and monthly active users, new users,
and user distribution across acquisition channels.

The outputs from this layer form the foundation for growth-related KPIs
and are used directly in Power BI visualisations.

**Growth Dashboard Observation:**
User growth during the selected period is primarily driven by new user acquisition rather than repeat engagement. A noticeable spike on 2017-07-05 aligns across daily active users and new users, indicating acquisition-led activity. Traffic is heavily concentrated from Google, suggesting limited channel diversification.
